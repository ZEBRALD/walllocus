# WallLocus

> **Remember every wallpaper's placement on every display.**

一个小巧、好改的 macOS 视频 / 图片壁纸工具。  
`Wall`（壁纸）+ `Locus`（位置、轨迹）——它记住每张壁纸在每块屏上的**位置轨迹**。

简体中文 · [English](README.md)

---

约 8900 行 Swift 的自包含 macOS 壁纸应用。无第三方依赖、无遥测、无需账号。只用 `swiftc` 构建——**不需要装完整 Xcode**。

## 它和别的壁纸软件有什么不同

**「显示器 × 壁纸」双维度记忆。**

每张壁纸在**每一块显示器**上都各自记住缩放模式、缩放倍率与水平/垂直偏移：

| 显示器      | 壁纸 A            | 壁纸 B           |
| -------- | --------------- | -------------- |
| 4K 外接显示器 | 150% · 偏移 −0.20 | 100% · 居中      |
| 笔记本内建屏   | 100% · 居中       | 73% · 偏移 +0.15 |
| 竖屏显示器    | 100% · 偏移 −0.55 | 100% · 居中      |

换显示器或换壁纸，之前的构图原样回来。多数壁纸应用最多给一个全局「填充/适应」开关；这里把构图当作**这一对组合**的属性。

## 把壁纸拖到屏幕上就应用

按住图库里的任意壁纸，直接拖出窗口甩到某块屏幕上，松手即应用 —— **拖到哪块屏就应用到哪块屏**。

- 拖拽时每块屏幕中央浮现一个提示卡片，光标压在哪张上就高亮哪张
- 拖到卡片外松手不会误应用
- 拖到左栏的显示器行同样可以应用（更稳妥的路径）
- 拖到桌面则把文件复制出去
- 可在设置里关闭

## 界面

三栏布局，参照 macOS 照片 App：

- **左栏** —— 显示器、壁纸库分类、预设。三组**各自独立选中**，可以同时选定「用这张图」和「投到那块屏」
- **中栏** —— 图库。五列网格贯穿到底，缩略图圆角按图片自身比例裁切
- **右栏** —— 选中素材的文件详情、构图参数与操作

左右两栏的边缘都能拖动改宽度，宽度会被记住。三栏共享同一块 liquid glass 底层，描边会随壁纸冷暖变色。左栏底部常驻一块信息区，显示当前作用范围的分辨率与正在使用的壁纸。

## 功能

- **视频与静态图片**，用自己的文件
- **每块显示器独立设置壁纸**，支持热插拔
- **缩放模式**：填充（裁剪）/ 适应（留黑边）/ 拉伸
- **缩放** 30–300%、**水平/垂直位置** ±100%，滑块旁有可输入的数值框（两位小数）
- **全屏时自动暂停**：检测某块屏是否被全屏应用完整覆盖（覆盖率 ≥96%），只暂停那一块
- **电池供电时暂停**（可选）
- **菜单栏常驻**：关窗后 Dock 图标消失，菜单栏图标保留
- **占用可控**：视频走 AVPlayerLayer 硬件解码，图片走 ImageIO 降采样；没有屏幕在用的位图会立刻释放
- **视频兼容性检测**：对 macOS 解不了的视频给出提示，并可一键把 HEV1 标签改成 HVC1（无需重新编码）
- **壁纸库 = 一个文件夹**：默认 `~/Pictures/WallLocus`，其下每个子文件夹自动成为一个分类
- **从访达直接拖入**：图片或视频拖到窗口任意位置即可
- **自动刷新**：切回应用、切换分类或显示器时会比对文件夹指纹，磁盘有变化才重扫
- **顶栏 + 按钮**添加壁纸，搜索框按文件名过滤
- **图库排序**：按文件名或修改时间，升序或降序
- **文件名可显隐**：关掉后缩略图会占满整个卡片
- **右键菜单**：卡片上可设为该屏壁纸、在访达中显示、移到废纸篓；分类可整类移到废纸篓；空白处可刷新图库、添加文件
- **预设**：记住「哪块屏用哪张壁纸」加上各自的构图，右键可应用 / 重命名 / 删除
- **中英双语界面**，跟随系统语言自动切换

## 拖进图库时会复制文件

从访达把图片拖进来，应用会把文件**复制**一份到壁纸文件夹，**原文件原地不动**：

| 拖入的文件 | 结果 |
| --- | --- |
| 已在壁纸文件夹里 | 不复制，直接用 |
| 在文件夹外 | 复制一份进去，原文件保留 |
| 同名冲突 | 自动加序号 `-2` / `-3`，绝不覆盖 |
| 复制失败 | 退回原路径，不阻断添加 |

这样图库自成一体——你之后在访达里移动或删除原文件，都不影响图库里的那份。代价是占用双份磁盘空间。

## 实测占用

Apple 芯片 + macOS 26，三块显示器（4096×2304 与 1080×1920）各显示一张静态图，库中 534 个素材：

| 指标 | 数值 |
| --- | --- |
| 物理内存（`footprint`） | **约 270 MB** |
| CPU（空闲静置） | **0.1 – 0.7 %** |
| 素材库 534 个 | 约 +2 MB |

内存主要由解码后的位图决定，因此随「驱动几块屏」和「源图多大」变化 —— 一张 4096×2776 的源图约 20 MB，最多保留 4 张，没有屏幕在用就立即释放。

素材库本身占用很少：缩略图按**实际显示尺寸 × 屏幕倍率**解码（Retina 上约 480px 长边），只处理可见的卡片，缓存上限 48 MB。**往库里加文件本身不会触发任何解码。**

> 注意：`ps` 的 RSS 显示高得多（约 355 MB），因为它把系统共享库的映射页也算进去了。要评估真实占用请用 `footprint -p <pid>` 或 `vmmap --summary`。

## 环境要求

- macOS **13.0** 及以上
- Apple 芯片或 Intel（用 `UNIVERSAL=1` 构建通用二进制）
- 只需 **Xcode Command Line Tools**（不需要完整 Xcode，也不需要 Homebrew）

## 构建

```bash
git clone https://github.com/ZEBRALD/walllocus.git
cd walllocus
./build.sh                 # 当前架构
UNIVERSAL=1 ./build.sh     # 通用二进制（arm64 + x86_64）
```

产物在 `build/WallLocus.app`。

## 安装

```bash
cp -R build/WallLocus.app /Applications/
xattr -dr com.apple.quarantine /Applications/WallLocus.app
open /Applications/WallLocus.app
```

本构建使用 **ad-hoc 签名且未公证**，首次启动会被 Gatekeeper 拦截。右键点应用选**打开**，或执行上面的 `xattr` 命令即可。

## 使用

1. 添加壁纸：点顶栏的 **+**，或者直接从访达把图片/视频**拖到窗口上**。加文件本身不会触发解码。
2. 在**左栏的显示器列表**里选一块屏，或选「全部显示器」。
3. 在网格里选中素材，点右栏的**设为该屏壁纸**；或者直接把素材**拖到那块屏幕上**。
4. 用滑块或直接输入数值调整**缩放模式 / 缩放 / 水平位置 / 垂直位置**。改动实时生效，并按「显示器 × 壁纸」分别记住。

改名请直接在**访达**里改 —— 界面不再提供第二套命名入口。

左栏底部的信息区显示当前作用范围的分辨率和正在使用的壁纸，它跟随你选的显示器，与是否选中素材无关。

## 架构说明

壁纸是一个处于桌面窗口层级的 `NSWindow`，里面承载 `AVPlayerLayer`（视频）或 `CALayer`（图片）。这让实现保持小巧、零依赖，但也带来两个有意的限制：

- **退出应用后壁纸消失**——它是应用自己的窗口，不是系统壁纸。
- **不支持锁屏壁纸**——锁屏由系统进程绘制，第三方窗口进不去。

要做这两点需要私有的 `WallpaperExtensionKit` 框架，超出小工具的范畴。

### 关于屏保

`.saver` 屏保在 **macOS 26 上不可用**：系统不再扫描 `~/Library/Screen Savers/`，
屏保面板只列出 ExtensionKit `.appex` 扩展（扩展点 `com.apple.screensaver`）。
完整证据链见 [SCREENSAVER.md](SCREENSAVER.md)。

## 配置

状态存在 bundle id `app.walllocus` 的 `UserDefaults` 中：

- `walllocus.state.v1` —— 素材库、每屏分配、每屏 × 每壁纸的调整量、预设
- `pauseOnFullscreen`、`pauseOnBattery` —— 行为开关
- `dragToApplyEnabled` —— 拖拽壁纸到屏幕即应用（默认开启）
- `paneSidebarWidth`、`paneDetailWidth` —— 左右栏宽度
- `showGridFileNames`、`librarySortKey`、`librarySortAscending` —— 图库显示与排序
- `sidebarGroupOrder` —— 左栏分组顺序
- `wallpaperFolder` —— 壁纸文件夹路径

开机自启用 `LaunchAgent`：`~/Library/LaunchAgents/app.walllocus.autostart.plist`。

## 常见问题

**视频黑屏。** 几乎可以确定是 HEV1 封装，macOS 只解 `hvc1`。应用会检测并给出一键修复（原文件保留为 `*.hev1bak.mp4`）。

**退出后壁纸没了。** 属预期行为，见「架构说明」。

**Dock 图标不见了。** 关窗后会主动隐藏，菜单栏图标仍在。

**在访达里加了图，应用里看不到。** 切回应用或切换一下分类即会自动刷新；也可以右键网格空白处选**立即刷新**。

**拖进来的图会不会把原文件移走？** 不会，是复制一份进壁纸文件夹。
